# House Price Prediction — Regression Analysis

A regression modeling project predicting residential property prices (in Lakhs INR) from
property, location, and listing attributes. Covers data cleaning, feature engineering, EDA,
multicollinearity checks, and a comparison of six regression approaches, ending in a tuned,
deployable model.

## Dataset

- **Source:** [`ml_regression_property_dataset.csv`](https://raw.githubusercontent.com/swapnilsaurav/MachineLearning/refs/heads/master/Examples/Regression/ml_regression_property_dataset.csv)
- **Size:** 1,000 rows × 26 columns (990 rows after removing 10 duplicates)
- **Target:** `Price_Lakhs` — property price in Lakhs (INR)
- **Features:** location (`City`, `Locality`, `Distance_to_Metro_km`, `Distance_to_CBD_km`),
  property specs (`BHK`, `Bathrooms`, `Built_Up_Area_sqft`, `Carpet_Area_sqft`, `Age_Years`,
  `Floor`, `Total_Floors`, `Property_Type`, `Furnishing_Status`, `Facing`, `Gated_Community`,
  `Parking_Spaces`), neighborhood/quality scores (`Crime_Index`, `Amenities_Score`,
  `Nearby_Schools`), cost fields (`Monthly_Maintenance_INR`, `Annual_Property_Tax_INR`),
  listing metadata (`Listing_Date`, `Seller_Type`, `Loan_Available`)

## Usage

1. Open `Regression_Housing_Price.ipynb` in Jupyter and run all cells top to bottom (the
   dataset is pulled directly from the URL above, no manual download needed).
2. This regenerates `housing_price_prediction.pkl`, the trained pipeline used for inference.
3. To predict on a new property, load the pipeline and pass a single-row DataFrame with the
   same columns used in training:

```python
import joblib
import pandas as pd

model = joblib.load("housing_price_prediction.pkl")

new_house = pd.DataFrame({
    "City": ["Hyderabad"], "Locality": ["Gachibowli"], "Property_Type": ["Apartment"],
    "BHK": [4], "Built_Up_Area_sqft": [1800], "Carpet_Area_sqft": [1200],
    "Age_Years": [2], "Floor": [10], "Total_Floors": [14], "Bathrooms": [4],
    "Parking_Spaces": [1], "Furnishing_Status": ["Furnished"], "Facing": ["East"],
    "Gated_Community": ["Yes"], "Distance_to_Metro_km": [11], "Distance_to_CBD_km": [17],
    "Nearby_Schools": [6], "Crime_Index": [5.4], "Amenities_Score": [7],
    "Monthly_Maintenance_INR": [8000], "Seller_Type": ["Owner"], "Loan_Available": ["Yes"],
    "Annual_Property_Tax_INR": [30000], "Floor_num": [10], "Days_Since_Listings": [400],
})

predicted_price_lakhs = model.predict(new_house)
```

## Pipeline Overview

1. **Data cleaning** — median/mode imputation for missing values, duplicate removal,
   standardized inconsistent text fields (`City` casing, `Floor` mixed text/numeric values,
   `Furnishing_Status`, `Gated_Community`), and typed `Listing_Date` as a datetime.
2. **Feature engineering** — derived `Listing_Year`, `Listing_Month`, `Listing_Quarter`,
   `Days_Since_Listings`, and a cleaned numeric `Floor_num` from raw `Floor` text.
3. **EDA** — distribution plots for price and maintenance cost, property type breakdown,
   price by city/age/area, a metro/CBD distance density plot, and a full correlation heatmap.
4. **Multicollinearity check (VIF)** — flagged the date-derived features as near-duplicates
   of `Listing_Date` (VIF up to 416); all but `Days_Since_Listings` were dropped.
5. **Preprocessing pipeline** — a `ColumnTransformer` combining median imputation + scaling
   for numeric features and most-frequent imputation + one-hot encoding for categoricals.
6. **Modeling** — baseline (mean predictor), simple linear regression, multiple linear
   regression, dimensionality reduction (SelectKBest, PCA), Ridge and Lasso regression
   (both hyperparameter-tuned via `GridSearchCV`), and polynomial regression.
7. **Deployment** — the best model is serialized with `joblib` for reuse without retraining.

## Results

| Model | R² | RMSE (Lakhs) |
|---|---|---|
| Baseline (mean predictor) | -0.003 | 55.17 |
| Simple Linear Regression (area only) | 0.365 | 43.90 |
| Multiple Linear Regression (all features) | 0.918 | 15.78 |
| MLR + SelectKBest (10 features) | 0.884 | 18.74 |
| MLR + PCA (5 components) | 0.856 | 20.90 |
| Ridge (α=1.0) | 0.918 | 15.73 |
| Ridge (tuned, α≈13.9) | 0.921 | — |
| **Lasso (tuned, α=0.13)** | **0.921** | **15.53** |
| Ridge + PCA | 0.856 | 20.90 |
| Polynomial (Age only, degree 2) | 0.054 | 53.59 |

**Best model:** Lasso Regression (α = 0.13) — chosen for deployment.

## Key Findings

- `Carpet_Area_sqft` (r = 0.86), `BHK` (r = 0.84), and `Bathrooms` (r = 0.76) are the
  strongest price drivers; `Built_Up_Area_sqft` correlates more modestly (r = 0.50).
- A single feature is a weak predictor on its own (R² of 0.05–0.36); the full multivariate
  model jumps to R² ≈ 0.92, so price is best explained jointly, not by any one attribute.
- Multiple Linear Regression already captures ~92% of price variance — the relationship
  between property features and price is largely linear.
- Dimensionality reduction (SelectKBest, PCA) slightly **hurt** performance, indicating the
  full feature set carries genuine, non-redundant signal rather than noise.
- Regularization gave a small but real edge over plain linear regression once tuned, with
  **Lasso (α = 0.13)** as the best overall performer, while also zeroing out weak features.
- `Age_Years` alone has a weak, non-linear relationship with price — not a strong standalone
  predictor.
